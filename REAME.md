# 🤖 Project FRIDAY

Project FRIDAY is an AI-powered desktop assistant built in Python.

It combines voice recognition, local AI (Ollama), Windows automation, and modular plugins to perform natural language commands.

---

## Features

- 🎤 Voice Recognition
- 🧠 Local AI using Ollama
- 🔊 Volume Control
- 💡 Brightness Control
- 📷 Camera Control
- 🌐 Browser Automation
- 📸 Screenshot Capture
- 📶 Wi-Fi Control
- 🖥️ System Information
- 🧩 Modular Plugin Architecture
- ⚡ Intent Detection
- 🎯 AI-powered Parameter Extraction

---

## Tech Stack

- Python
- Ollama
- Edge-TTS
- SpeechRecognition
- psutil
- pyautogui
- OpenCV
- Windows APIs
